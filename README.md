# Reed-Bellows.github.io

My personal website: **https://reed-bellows.github.io/**

I'm Reed Bellows, a first-year student at Cornell studying Biometry and Statistics. This site covers who I am, what I've done and what I'm working on.

## Pages

| Page | What's on it |
| --- | --- |
| [Home](index.html) | Introduction and links to every section |
| [Background](background.html) | Who I am, where I'm from, and my family |
| [Experience](experience.html) | School, work and organizations, as a clickable timeline |
| [Projects](projects.html) | Internship case studies and personal coding projects |
| [Skills](skills.html) | R, statistics, finance and leadership |
| [Interests](interests.html) | Club basketball, fishing, football and reading |

## How it's built

Plain HTML and CSS, with no frameworks or build step. Every page shares one stylesheet, [style.css](style.css). The site is hosted on GitHub Pages and updates automatically when changes are pushed to `main`.

## Run it locally

From this folder:

```bash
python3 -m http.server 8000
```

Then open http://localhost:8000/.
